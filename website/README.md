# LEO Website Dashboard - Easy Setup

## 1. Where to put this folder

Your project should look like this:

LEO_Student_MultiAngle/
│
├── results/
│   ├── macro_with_Rician5deg_100km.json
│   ├── macro_with_Rician10deg_100km.json
│   ├── ...
│   └── macro_no_Rician90deg_100km.json
│
├── figures/
│
├── simulation_student.py
├── channel.py
├── networkGeometry.py
├── params.py
│
└── website/
    ├── index.html
    ├── style.css
    ├── app.js
    └── server.py

Copy the `website` folder from this ZIP into your project root.

## 2. Start the website

Open PowerShell in the project root.

Run:

python website/server.py

Then open:

http://127.0.0.1:8000

## 3. What you can change

- Simulation Mode: Rician or Macro / No Rician
- Elevation Angle: 5° to 90° in 5° steps
- Click LOAD RESULT

The dashboard then reads the matching JSON file from your `results/` folder.

## 4. IMPORTANT: this version is Demo Mode

The website does NOT run the full Python simulation when you move the slider.

Instead:

Elevation 55° → website reads the saved 55° JSON → graphs update.

This is intentional. It makes the classroom demo fast and reliable.

## 5. Your saved data

Each JSON result contains:

- user_positions: simulated user coordinates
- n_user: number of simulated users
- satellite_position: satellite position used for that frame
- snr: SNR value for each user
- sinr: SINR value for each user
- beam_index: serving beam for each user
- center_beam_gain_dB: beam gain values
- beam_centers: locations of the 19 beam centers
- r_footprint: footprint radius used by the simulation
- elevation_angle: actual elevation represented by the selected satellite frame
- requested_elevation_angle: angle you selected/requested
- frame_index: selected satellite frame

## 6. Figures vs Results

`results/` = numerical simulation data. The website uses this.

`figures/` = PNG/static graphs generated by the plotting script. The website does not need these files for its calculations.

## 7. If the teacher asks "Is this real-time?"

Say:

"The dashboard is interactive and retrieves the simulation results for the selected elevation angle. The underlying physics simulation is precomputed to keep the demonstration fast and stable. A live-calculation backend can be added later."

## 8. If you want arbitrary angles such as 57°

The current data is saved at:
5°, 10°, 15°, ... 90°.

So this first website intentionally uses those angles.

A second version can add a LIVE SIMULATION button that sends an arbitrary angle to Python and calculates a new result.


## TROUBLESHOOTING

### Slider moves but results do not change
That usually means the browser cannot find the JSON file.

For example, selecting 55° in Rician mode requires:

results/macro_with_Rician55deg_100km.json

Selecting 55° in Macro mode requires:

results/macro_no_Rician55deg_100km.json

### Everything is white / graphs are blank
Use the `app.js` from this FIXED ZIP. The previous version had a canvas resizing bug that cleared the canvas immediately after drawing setup.

### Do NOT double-click index.html
Do not open the HTML directly from File Explorer.

Start the server:

python website/server.py

Then use:

http://127.0.0.1:8000

### Quick test
After starting the server, the top-right status should say:

Loaded: 55°

Then move the slider to 60° and click:

LOAD SELECTED ANGLE

The requested elevation card should change to 60°.
